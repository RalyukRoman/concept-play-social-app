# ConcepPlay
ConcepPlay is a desktop application built on XAML that allows users to publish, view and share game concepts. The platform is aimed at developers, designers and game dev enthusiasts who want to share ideas and find inspiration.

> The project is built on a client-server architecture and consists of three parts: a client application, a server and a separate library for working with the database.

## Launch
1. Clone the repository
``` git clone <repo-url> ```
2. Open the solution (.sln)
3. Install dependencies (NuGet)
4. Configure the database
5. Start the server
6. Start the client

## Utils
- XAML (WPF / UI)
- EntityFrameworkCore (SQL Server)
- Newtonsoft.Json
- Client-Server Architecture
- DLL (Data Access Layer)
